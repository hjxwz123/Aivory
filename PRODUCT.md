# Aivory Product Context

## Register

product

## Users

Individuals and teams use this self-hosted AI workspace for conversations,
research, creation, shared knowledge and administration. Chat runs on desktop
and mobile browsers as well as the packaged desktop client.

## Product Purpose

Keep conversations, files, research and team projects together while letting
users choose their AI services and control their data. The current chat task
is to make the period before an assistant response feel responsive and clear.

## Brand Personality

Calm, clear and distinctive. Preserve the existing Aivory identity, semantic
theme tokens and reading-focused conversation layout. The design-token file
defines Geist body text, violet primary actions and a secondary AI-state color.

## Anti-references

- Inconsistent interaction states between equivalent pages or chat surfaces.
- Uninformative loading indicators that make a live request appear stuck.
- Invented progress percentages or claims about work the model has not reported.
- Decorative motion that competes with reading and task completion.

## Design Principles

- Acknowledge user actions immediately.
- Show genuine model and tool activity when it is available.
- Render responses progressively as soon as content arrives.
- Reuse components and semantic tokens across equivalent surfaces.
- Keep feedback compact, readable and appropriate for long waits.
- Use animation as the primary reply-wait feedback; keep its description
  available to screen readers without visible explanatory paragraphs.

## Accessibility & Inclusion

Preserve the project's reduced-motion support, keyboard interactions and
accessible labels. Loading feedback must have a textual equivalent, remain
readable in both themes and fit narrow mobile and side-panel layouts.
