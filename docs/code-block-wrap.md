# 代码块自动换行

代码块支持独立切换自动换行，设置 → 外观提供“代码块默认自动换行”。
全局默认关闭，登录账户的默认值跨设备保存；未登录时仅保存到当前浏览器。

## 交互和继承规则

代码块工具栏的换行按钮位于复制按钮左侧，开启时显示选中状态。手动调整后
出现“恢复默认”按钮，点击后重新跟随全局设置。按钮支持键盘操作、Tooltip
和 `aria-pressed`，流式生成期间仍可使用。

| 单块状态 | 显示规则 | 全局设置改变时 |
| --- | --- | --- |
| `null` | 跟随全局默认 | 立即跟随 |
| `true` | 强制换行 | 保持换行 |
| `false` | 强制不换行 | 保持不换行 |

实际状态为 `wrapOverride ?? appearance.codeBlockWrap`。单块值即使恰好与全局
值相同，也保留显式覆盖身份；只有恢复默认才清除覆盖。

单块覆盖仅存在于当前组件展示生命周期。流式追加、最终高亮及普通重渲染
保留选择；刷新、会话切换、代码块卸载或账户切换后恢复继承。回到先前账户
不会复活它的旧单块覆盖。

换行只改变布局，不改变原文、缩进或原始换行符。复制、Python 运行、HTML
预览及分享继续使用原始代码字符串。

## 设置存储与接口

| 层级 | 字段 | 类型 |
| --- | --- | --- |
| 前端设置 | `appearance.codeBlockWrap` | `boolean` |
| 浏览器缓存 | `aivory.settings` 内的 `appearance.codeBlockWrap` | `boolean` |
| 用户资料和数据库 | `users.settings.code_block_wrap` | JSON 布尔值 |
| 单块展示状态 | `wrapOverride` | `boolean \| null` |

本地缓存只接受布尔值。云端缺少字段或不是 `true` 时，默认关闭，避免登录
另一个账户时继承旧账户的浏览器缓存。不新增数据库列或迁移。

```http
PATCH /api/me/settings
Content-Type: application/json

{"code_block_wrap": true}
```

服务端将字段加入用户设置白名单，只接受 `true` 或 `false`。字符串、数字、
对象、数组和 `null` 返回 `400`，整个请求不写入；省略字段保留原值。现有
事务式 JSON 合并和认证缓存失效机制继续生效。

前端先乐观更新并禁用该设置开关，随后确认响应中存在请求的布尔值。网络
失败、旧服务端静默过滤字段或响应值不匹配都会回滚并提示失败。保存请求
带账户及请求身份，过时回调不会影响新账户。

保存中暂存的值优先于旧资料快照，临时请求状态不写入浏览器缓存。保存成功
后只把本次 PATCH 接受的字段合入本地用户资料，避免并发请求的完整旧快照
覆盖其他已保存设置。旧资料刷新通过设置修订号保护最新的确认值。

登录、刷新页面和进入外观设置时读取云端偏好；回到前台时也刷新用户资料，
同一页面的焦点/可见性事件间隔至少 30 秒，隐藏或保存期间不刷新。跨设备
同步采用服务端持久化和这些刷新时点，多设备写入以最后提交的值为准。

## 渲染范围

普通消息、启用 Markdown 的用户消息、列表/引用内的嵌套代码以及私密聊天
共用展示层 `CodeBlockFrame` 和 `useCodeWrap`。嵌套 token 按块路径递归渲染，
保留有序列表起始编号、任务勾选、公式、行内格式及现有 HTML/链接处理。

私密代码块仅有换行及恢复默认操作，不加载普通代码块的运行、预览、分享
或高亮逻辑。普通嵌套代码块另有原文复制，也不新增运行或自动预览。

行内代码、Mermaid 图表和代码运行结果维持独立展示规则。

| 正文样式 | 不换行 | 自动换行 |
| --- | --- | --- |
| `white-space` | `pre` | `pre-wrap` |
| `overflow-wrap` | `normal` | `anywhere` |
| `word-break` | `normal` | `normal` |
| 横向溢出 | `auto` | `auto` 兜底 |

规则只作用于带 `data-code-body` 的正文及其直接 `code` 子元素；运行结果不
受影响。外层保留 `overflow-clip`，工具栏继续吸顶。换行不触发重新高亮，
最终 Shiki 渲染也不改变单块选择。

## 验证和交付

前端回归覆盖缓存规范化、云端默认、显式关闭优先级、恢复默认、账户变化、
保存失败、旧响应、前台刷新、流式更新、原文复制/运行/预览及嵌套/私密渲染。
API 用例覆盖保存、读回、字段省略、非法类型和整个请求拒绝。

```sh
npm test
npm run typecheck
npm run test:code-wrap
cd server
go test ./internal/api ./internal/store
```

浏览器回归使用已安装的 Chrome/Edge 或 `CHROME_PATH`，在 5196 端口启动
临时 Vite 服务，验证真实 URL/中文长行宽度、设置继承、原文剪贴板、最终
Shiki 高亮、键盘操作、HTML 沙箱预览及 320px 视口/280px 内容区布局。Vite
缓存和浏览器配置均写入临时目录并在结束时清理，不使用日常浏览器配置。

实施提交按接口、设置同步、代码块展示、浏览器回归和文档四阶段保留在
`dev`。完成检查后以 `--no-ff` 合并到 `main`，合并说明记录提交范围和结果。
发布时先部署后端再部署前端，确保新设置能落库；旧客户端兼容新字段。
