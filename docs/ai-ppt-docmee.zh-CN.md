# AI PPT（文多多 Docmee）使用与配置

[English](./ai-ppt-docmee.md)

Aivory 通过 Docmee 的 iframe SDK 提供 AI PPT 创作台。管理员在系统中配置
Docmee 后，登录用户可以在 Aivory 内创建演示文稿；密钥始终保留在服务端，浏览器只会
拿到与当前用户绑定的短期 token。每份成功生成的 PPT 可按管理员设定扣除积分。

## 可用条件和入口

AI PPT 是可选能力，默认不显示。只有同时满足以下条件时，侧边栏才显示 **AI PPT**：

1. 管理员已保存可用的 Docmee API Key；
2. 管理员已打开「启用 AI PPT」开关。若该开关从未保存过，有 API Key 时会自动视为启用；
   一旦明确保存为关闭，关闭状态优先。

配置缺失或开关关闭时，侧边栏没有 PPT 入口。`/ppt` 仍保留为可访问路由，方便旧书签
和链接正常落地，但页面会显示不可用状态，不能创建 token 或开始生成。

## 管理员配置

进入「**管理后台 → 积分与配额 → AI PPT（文多多 Docmee）**」，依次完成：

1. 填写 **Docmee API Key**。保存后管理端只显示掩码，不会将原始 Key 回传浏览器。
2. 设置 **每份 PPT 所需积分**。填 `0` 时不收费；只有平台积分系统已开启且该值大于 `0`
   才会在生成时扣积分。
3. 选择创作器版本：`v2` 是对话式创作器，`v1` 是分步式创作器。通常选择 `v2`。
4. 按需调整 token 有效期、API 地址、iframe 域名、SDK URL 和 SDK base URL。中国大陆默认
   配置无需修改；国际版、反向代理和自托管 SDK 使用这些字段。
5. 打开 **启用 AI PPT**。开关会独立保存，保存成功后前端会刷新共享配置，用户无需刷新
   页面即可看到或隐藏侧边栏入口。

推荐先保存 API Key 与价格，再打开开关。配置页会校验 URL；地址不合法时整次保存会被拒绝，
不会只写入部分字段。

## 用户使用流程

启用后，任意登录用户可从侧边栏进入 **AI PPT**：

1. 打开创作台并输入主题、要求或内容；
2. 在开始生成前，Aivory 检查当前用户可用积分；
3. 余额足够时，Docmee 生成演示文稿；
4. 生成完成后，用户可在创作台中继续编辑、导出或下载。

AI PPT 当前不按工作空间设置单独授权。无论用户位于个人空间还是工作空间，使用权和积分
余额都属于发起生成的登录用户。

## 积分、预扣和用量

每次生成使用三步流程，客户端不能传入价格或绕过扣费：

1. **预扣**：开始生成前暂时冻结一份 PPT 的积分。余额不足时直接阻止生成并提示充值。
2. **结算**：Docmee 返回 PPT ID 后，Aivory 用该 ID 结算一次扣费。同一份 PPT 因 SDK
   重试、刷新页面或重复回调而被再次上报时，不会重复扣费。
3. **释放**：生成失败、放弃或未完成的预扣会释放；未完成但无法回调的预扣也会在 30 分钟
   后自动过期。

成功结算会在管理员「用量与计费」中留下 `ppt` 用途记录，并参与使用统计。若平台积分
系统未启用，或每份价格设置为 `0`，创作台保持可用且不会扣费。

## 国际版、自托管 SDK 与代理

默认使用中国大陆 Docmee 服务。以下场景通过管理端字段配置：

| 场景 | 配置方式 |
| --- | --- |
| 国际版 | 将 **Domain** 设为 `https://app.xpptx.com`，并填写账户对应的国际 API 地址。 |
| 自托管 SDK | 将 **SDK URL** 指向自行托管的 Docmee SDK 脚本或受信任的内网镜像。 |
| 自建代理 | 设置 **Domain**、**SDK base URL** 与服务端 **API base URL**，让浏览器和服务端通过自己的代理访问 Docmee。 |

部署环境也支持 `DOCMEE_API_KEY`、`DOCMEE_API_BASE_URL`、`DOCMEE_DOMAIN`、
`DOCMEE_SDK_URL` 和 `DOCMEE_SDK_BASE_URL` 作为数据库字段为空时的兜底。运行中的
数据库设置优先，常规部署建议优先通过管理后台配置；修改环境变量需要重启 API 服务。

## 安全与故障处理

- Docmee API Key 只保存在服务端设置中。浏览器只获取短期、用户范围内的 token。
- token 铸造、预扣、结算与释放都要求登录，且用户不能操作其他用户的生成尝试。
- 上游服务故障会显示通用服务不可用提示，不会向用户暴露上游响应细节或密钥。
- 未配置、关闭或密钥无效时，不会显示半可用的创作界面。先检查开关和 API Key，再检查
  API 地址或代理配置。
