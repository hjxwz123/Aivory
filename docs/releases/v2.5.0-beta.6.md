# Aivory v2.5.0-beta.6

> Test release / prerelease.

This release contains every application change merged since beta.5: keyless DuckDuckGo search, a dedicated AI PPT administration page, refreshed authentication screens, clearer message actions, response-state fixes, and a corrected chat-width control.

## Web Search

- Add DuckDuckGo as an explicit, keyless provider for `aivory_web_search`, alongside SearXNG, Serper, Brave, and Tavily. Its `ddg` alias is also accepted in server configuration. The `auto` provider still chooses only an existing keyed or SearXNG backend.
- Query DuckDuckGo's HTML endpoint first, then try its lite endpoint when the first request fails, is challenged, or yields no parsed rows. Limit a page to ten results, skip recognized HTML ads, unwrap DuckDuckGo tracking redirects, reject non-HTTP(S) destinations, and return titles, snippets, and citations in the existing tool format.
- Report recognized anti-bot challenges, HTTP failures, and rate limits with provider-specific guidance. Treat a valid empty result page as an empty search, while keeping the administrator informed when both endpoints fail.
- Show the new provider and its server-IP throttling caveat in Admin > Tools. The onboarding search step accepts it without a key or URL. Update the English, Chinese, Traditional Chinese, Japanese, and French admin labels, the README tool table, and both environment templates. The templates now also list Tavily as a keyed option.

## AI PPT Administration

- Move Docmee / AI PPT configuration from Credits and quotas to its own Admin > Capabilities and integrations > AI PPT page. Credits and quotas keeps the platform-wide credit conversion and general usage controls.
- Keep the enable switch, API key and endpoint, creation and edit prices, default template, upload limit, token lifetime, SDK and international-domain settings, vendor balance lookup, and shared-template administration together on the new page.
- Save only AI PPT-owned settings from that page; changing the enable switch takes effect immediately. Show a warning and a link to Credits and quotas when PPT pricing is set but platform credits are disabled. Update navigation, translations, and the AI PPT integration guide for the new location.

## Authentication

- Redesign the login, registration, password-recovery, and first-run setup screens around a shared responsive layout and labeled form fields. Refresh the brand mark, language control, form copy, and localized labels in all five supported languages.
- Add theme-aware artwork: light-theme SVG scenes and dark-theme WebGL scenes, selected from each theme's collection. Lazy-load the artwork, show a visual fallback while it loads, and transition between prepared scenes when the theme changes. Respect reduced-motion preferences during that transition.
- Keep password, OAuth, passkey, two-factor, email verification, and password-reset paths in the new form layout, with inline errors, loading states, and the existing resend-code controls.

## Chat and Appearance

- Put **Fork to new conversation** directly in the desktop message toolbar with a tooltip; remove the duplicate desktop overflow actions. Group copy/edit, regenerate/fork, export, feedback/report, and delete in a consistent order, including the mobile action sheet.
- Keep local copy/edit actions available for an optimistic user message while the assistant replies, but wait for a persisted message ID before exposing server-targeted actions such as delete, feedback, regenerate, or fork.
- Avoid duplicating the same pre-tool narration when it already appears as the last thinking item, including after a stopped response is reconciled from the server.
- Align the five chat-width slider stops and labels, with a stable range thumb and keyboard-accessible stop buttons.

## Other Maintenance

- Ignore `server/bin/`, where local API builds can place a Windows executable.
- Preserve the original commits and authorship from the DuckDuckGo contribution in [PR #39](https://github.com/hjxwz123/Aivory/pull/39).

## Known Limitations

DuckDuckGo's public endpoints can challenge or rate-limit server IPs. In this beta, a query containing one of the challenge-marker strings may be mistaken for a blocked page, and a lite result without a snippet can shift snippet-to-citation pairing. Use Serper, Brave, Tavily, or SearXNG where search reliability is required.

## Upgrade

This is a test release. Back up the database and application data before deploying. Once the application, updater, and sandbox images for this tag have finished publishing, set the deployment's actual `deploy/.env` to:

```dotenv
IMAGE_TAG=2.5.0-beta.6
UPDATER_IMAGE_TAG=2.5.0-beta.6
```

Remove or align any explicit `APP_IMAGE_TAG` or `SANDBOX_IMAGE_TAG` overrides, then verify and deploy:

```bash
cd deploy
docker compose --env-file .env -f docker-compose.prod.yml config --images
docker compose --env-file .env -f docker-compose.prod.yml pull
docker compose --env-file .env -f docker-compose.prod.yml up -d --no-build
```
