# Aivory v2.5.2-beta.11

Test release covering changes since **v2.5.2-beta.10**. Improves mobile administration layouts, standardizes interactive controls, adds configurable reply waiting animations, and polishes authentication and workspace administration flows.

## Administration UI

- Add dedicated mobile panels and responsive layouts for dialogs, selects, popovers, forms, tabs and administration list tools.
- Keep administration tables, editors and detail views within narrow mobile viewports without horizontal overflow.
- Align the announcement image upload control with the surrounding form fields on the global and workspace announcement editors.
- Replace the server archive native select on **Admin > Backup** with the shared custom Select component, including the mobile bottom selection panel.
- Keep the existing empty, loading and error states while preserving keyboard and screen-reader labels.

## Chat and Authentication

- Add configurable assistant reply waiting animations with previews in appearance settings; the default remains the paper-plane animation.
- Use a compact flowing light bar for the response wait state so long model requests provide immediate visual feedback without excessive copy.
- Arrange third-party sign-in methods responsively and keep passkey sign-in as a clear separate action.

## Workspace and Domain Administration

- Allow changing the target workspace for domain rules that have not enrolled members yet, while preserving existing member bindings once enrollment has started.
- Keep workspace selection optional for new domain rules and prevent personal-space locking when no workspace is selected.

## Validation

- TypeScript checking: `npm run typecheck`
- Production frontend build: `NODE_OPTIONS=--max-old-space-size=8192 npm run build`
- Site access browser checks: `node tests/browser/run-site-access.mjs`
- Full administration table browser checks and mobile layout checks were run during this release cycle.

This release is marked as a GitHub prerelease.
