# Aivory v2.5.0-beta.7

> Test release / prerelease.

This release includes the application changes since beta.6.

## Chat and Knowledge Bases

- Wait for a stopped generation to reach its final server state before sending an edited question again. A delayed stop response can no longer restore a round after it has been deleted.
- Allow the original opening round to be deleted when its only answer was stopped. Preserve the existing protection when another answer branch exists.
- Keep the knowledge-base selection control available in chat threads without project files.
- Remove the introductory explanation above the knowledge-base list while retaining the empty-state and creation guidance.

## AI PPT

- Synchronize the edited presentation before closing the external editor. Keep the editor open and report the error if synchronization fails.
- Simplify the editor actions and presentation views by removing redundant explanatory text, and keep the outline rewrite input inside the dialog body.

## Upgrade

This is a test release. Back up the database and application data before deploying. After the application, updater, and sandbox images for this tag finish publishing, set the deployment's actual `deploy/.env` to:

```dotenv
IMAGE_TAG=2.5.0-beta.7
UPDATER_IMAGE_TAG=2.5.0-beta.7
```

Remove or align any explicit `APP_IMAGE_TAG` or `SANDBOX_IMAGE_TAG` overrides, then verify and deploy:

```bash
cd deploy
docker compose --env-file .env -f docker-compose.prod.yml config --images
docker compose --env-file .env -f docker-compose.prod.yml pull
docker compose --env-file .env -f docker-compose.prod.yml up -d --no-build
```
