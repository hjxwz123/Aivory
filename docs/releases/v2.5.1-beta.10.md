# Aivory v2.5.1-beta.10

> Test release / prerelease fixing desktop drawer positioning and macOS fullscreen layout.

## Desktop Layout Fixes

- Keep administrator create/edit drawers anchored to the right edge. Desktop titlebar styling now distinguishes side drawers from centered dialogs, preventing drawers from being shifted halfway down the window.
- Apply the same content-area bounds to shared left/right sheets, including audit logs and call/error log details. Long forms scroll inside their drawer; centered confirmations retain their normal positioning.
- Remove the macOS titlebar inset and drag strip in native and HTML fullscreen. Restore them when returning to an ordinary window, including after a page reload in fullscreen.
- Attach titlebar behavior after the native window is created so main windows, preview windows, checkout windows, and server setup windows receive the correct fullscreen events.
- Extend the page and sidebar surfaces into the ordinary-window title area. Colors follow the active theme, and the sidebar section follows sidebar resizing and visibility.
- Let dialog and sheet overlays cover the title area instead of leaving a bright strip above the overlay.

This is a desktop layout update. It does not change API routing, model protocols, or database schemas. Existing server settings persist through app updates.

## Validation

- Real Electron smoke checks on macOS: native fullscreen entry/exit, reload in fullscreen, HTML fullscreen entry/exit, draggable theme-aware chrome, sidebar resize/removal, and viewport bounds without document scrolling.
- Browser checks using real administrator channel/model/skill editors and audit/call-error detail sheets: light/dark themes, desktop and narrow windows, web/ordinary desktop/fullscreen layout, create/edit consistency, centered confirmations, overlay coverage, and fullscreen transitions with an open drawer.
- TypeScript, targeted ESLint, JavaScript syntax checks, and Git whitespace checks.
- Existing Electron checks passed for minimizing/restoring without losing drafts, browser authorization, local frontend/API transport, streaming, uploads, voice sockets, payments, previews, offline recovery, persistent sessions, and explicit Quit.
