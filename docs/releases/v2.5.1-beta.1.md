# Aivory v2.5.1-beta.1

> Test release / prerelease.

This release contains every application change merged since v2.5.0: a deeper Deep Research engine, browser speech recognition with per-second pricing for server-side transcription, USD pricing for AI PPT, and a refined chat home, sidebar, and private chat.

## Deep Research

- Offer Deep Research for models whose built-in tools are a custom list without web search. The engine runs its own search pipeline, so the model's default web-search tool no longer gates it. Global, group, and workspace tool policies still apply.
- Replace the single search-and-verify pass with an iterative search, read, and reflect loop. Every fetched page is read against its sub-question with the task model and distilled into dated facts, a relevance verdict, and follow-up leads. Between rounds a reflection writes to a research log, follows promising leads, and may add sub-questions up to a cap.
- Keep researching until a minimum number of rounds have run and a minimum number of relevant sources have been read in full, then cross-validate the reading notes into confirmed, disputed, and unverified findings before the report is written. Source-reading calls appear under their own **Deep Research source reading** category in usage records.
- Give the research rounds their own time budget, separate from cross-validation and report writing, so a long investigation cannot starve the report.
- Show the live phase and the research log in the research panel.

## Voice Input

- Add browser speech recognition (Web Speech API) as a free alternative to server-side transcription. It is available only in browsers that provide the API, and recognition quality depends on the browser.
- Add **Default speech recognition** to Settings > Models, with the administrator's model-based service and the browser engine. Each option shows its availability and approximate cost per minute. When no choice has been saved, Aivory follows whether a transcription provider is configured, and it tells the user when the chosen engine is unavailable and another one will be used.
- Price server-side speech recognition per second in USD on **Admin > Voice**. The price is charged in credits at the platform's `credits_per_usd` rate; a partial second counts as one second, `0` means free, administrators are not charged, and browser recognition is always free. Uploaded clips are measured from their WAV samples, and a live session is limited to what the user's balance can cover and stops with a message when credits run out.
- Show specific messages for insufficient credits, a missing microphone, permission and network failures, and unsupported browsers.

## AI PPT Pricing

- Price AI PPT decks and edits in USD (`docmee_price_per_ppt_usd` and `docmee_edit_price_usd`). The charge is converted to credits at `credits_per_usd`, and the AI PPT administration page shows the credit equivalent.
- Keep the existing credit-denominated prices (`docmee_credits_per_ppt` and `docmee_edit_credits`) charging exactly what they did until a USD price is saved. The administration page shows their USD equivalent, so upgrading does not change any price by itself.

## Chat Home, Sidebar, and Private Chat

- Open private chat on the same screen as a new conversation. The greeting, suggestions, and sidebar are shared; only the composer changes, and a **Private** badge inside it names the mode. Entering it no longer shows a loading screen, because the page ships with the chat route and reuses the already loaded model list.
- Replace the horizontally scrolling suggestion cards with compact prompt chips, a shuffle button, and a short **Pick up where you left off** list of the latest conversations. Choosing a suggestion puts its prompt in the composer so it can be completed before sending, instead of sending it immediately.
- Animate the composer from its centered home position to the conversation when the first message is sent, and cross-fade only the composer when entering or leaving private chat. Browsers without View Transitions, and users who prefer reduced motion, get the same change without the animation.
- Give every sidebar row one shared hover and selected style. Use readable sentence-case section labels, show keyboard shortcuts as one compact chip on hover, fade long titles with a tooltip instead of scrolling them, reveal row menus on hover, and fade the list edges. Collapsing the sidebar keeps every icon in place while the labels fade, and the collapsed rail carries its own expand control.
- Grow menus, popovers, selects, and tooltips from the side of their trigger. Open the home composer's model and feature menus downward so they do not cover the greeting, and switch between the voice, send, and stop buttons with a short transition.
- List recent conversations first in the command menu (Ctrl/Cmd+K), with relative times, so Enter opens the latest conversation instead of starting a new one. The sidebar toggle now has the correct icon, and shortcuts are written the same way everywhere.
- On phones, use a one-line composer placeholder and a swipeable row of suggestions above the composer.

## Compatibility

- This release adds no database migrations. The new pricing values are stored as administrator settings.
- Deep Research defaults are higher: up to 8 rounds, at least 12 sources read in full, a 20-minute research budget, and a 45-minute overall limit. A run can therefore take longer and make more model and search calls. Lower the `AIVORY_LLM_DR_*` limits documented in the configuration reference to keep the previous cost profile.
- Speech recognition and AI PPT charges use credits only when the platform's credit system is enabled with a non-zero `credits_per_usd` value.

## Upgrade

This is a test release. Back up the database and application data before deploying. After the application, updater, and sandbox images for this tag finish publishing, set the deployment's actual `deploy/.env` to:

```dotenv
IMAGE_TAG=2.5.1-beta.1
UPDATER_IMAGE_TAG=2.5.1-beta.1
```

Remove or align any explicit `APP_IMAGE_TAG` or `SANDBOX_IMAGE_TAG` overrides, then verify and deploy:

```bash
cd deploy
docker compose --env-file .env -f docker-compose.prod.yml config --images
docker compose --env-file .env -f docker-compose.prod.yml pull
docker compose --env-file .env -f docker-compose.prod.yml up -d --no-build
```
