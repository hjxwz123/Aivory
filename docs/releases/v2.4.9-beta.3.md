# Aivory v2.4.9-beta.3

> Test release / prerelease. This is not a stable production release.

`v2.4.9-beta.3` adds WeCom sign-in, administrator management for public HTML preview links, Tavily as a web search backend, and more reliable streamed reasoning output. Back up application data before testing and use a staging deployment where possible.

## What to test

### WeCom sign-in

- Administrators can configure Enterprise WeChat (WeCom) as an OAuth provider from the authentication settings.
- Login callbacks validate provider state and keep WeCom identities separated from identities issued by other OAuth providers.
- Existing OAuth configuration, backup, restore, and multilingual administration flows recognize the WeCom provider.

### Public HTML preview administration

- Administrators can list public HTML preview links, inspect their owner and creation time, and delete links that should no longer be available.
- Deleted preview links are rejected by the public endpoint instead of continuing to serve cached HTML.
- Preview management is available from the administrator navigation and is localized in all supported interface languages.

### Tavily web search and streamed reasoning

- Tavily is available as an `aivory_web_search` backend alongside Serper, Brave, and SearXNG.
- Administrators can configure the Tavily API key and verify readiness from onboarding and tool settings.
- Identical reasoning deltas returned simultaneously in `reasoning` and `reasoning_content` are emitted once, preventing duplicated reasoning text.

## Upgrade and deployment

Administrators already running `v2.4.9-beta.2` can select `v2.4.9-beta.3` from **System update** after the beta3 container images finish publishing. A prerelease does not enable the stable-update badge.

For a manual Compose update, preserve the deployment's existing environment values and set:

```dotenv
APP_IMAGE_TAG=2.4.9-beta.3
UPDATER_IMAGE_TAG=2.4.9-beta.3
```

Then pull and recreate the application and updater services using the deployment's existing Compose file:

```bash
docker compose -f docker-compose.prod.yml pull app updater
docker compose -f docker-compose.prod.yml up -d --no-deps --force-recreate updater app
```

Do not replace an existing deployment environment file with an example. Preserve the existing Compose project name, data paths, database credentials, host ports, and secrets.
