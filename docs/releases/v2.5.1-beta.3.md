# Aivory v2.5.1-beta.3

> Test release / prerelease.

This is a new build of the beta.2 feature set. There are no new application features or fixes since v2.5.1-beta.2; this release updates the package version, About page, release notes, and container image version to `2.5.1-beta.3`.

## Included Features

- Stable loading states for recent conversations and the model picker on the chat home, with reserved space, skeletons, fade-in transitions, and retry states.
- A spinner and loading message for sidebar history during initial loading and workspace switches, with cached history retained during a refresh of the same workspace.
- Independent code-block wrapping controls and an account default saved across devices.

See the [beta.2 release notes](https://github.com/hjxwz123/Aivory/releases/tag/v2.5.1-beta.2) for the full description of these features.

## Compatibility and Validation

- This release adds no database migrations and uses the same dependencies as beta.2.
- The unchanged application code passed 894 frontend tests across 151 test files during beta.2 validation. TypeScript checks and the production build are checked again for this version.
- All four release images are built for `linux/amd64` and `linux/arm64`.

## Upgrade

After the images for this tag finish publishing, set the deployment's `deploy/.env` to:

```dotenv
IMAGE_TAG=2.5.1-beta.3
UPDATER_IMAGE_TAG=2.5.1-beta.3
```

Remove or align any explicit `APP_IMAGE_TAG` or `SANDBOX_IMAGE_TAG` overrides, then verify and deploy:

```bash
cd deploy
docker compose --env-file .env -f docker-compose.prod.yml config --images
docker compose --env-file .env -f docker-compose.prod.yml pull
docker compose --env-file .env -f docker-compose.prod.yml up -d --no-build
```

The release publishes `aivory-app`, `aivory-updater`, `aivory-sandbox`, and `aivory-sandbox-sidecar` under `ghcr.io/hjxwz123`, each tagged `2.5.1-beta.3`.
