# Aivory v2.5.1-beta.4

> Test release / prerelease.

This release refreshes the administrator console, Files, and knowledge-base pages with consistent typography, clearer document status, and stable loading states. It also simplifies the speech-recognition setting description in all five supported languages.

## Administrator Console

- Align the console sidebar, page headers, tabs, and footer with the application's shared layout and design tokens.
- Replace serif administrator headings with the shared sans-serif scale so Chinese headings render consistently and the console follows the Appearance font preference.
- Reuse settings sections and rows across administrator configuration and user settings. Header actions, text sizes, and corner radii follow a consistent scale.

## Files

- Show matching list and preview skeletons on initial load. Refreshing, searching, filtering, and paging retain existing rows with a thin progress indicator.
- Give files and folders clearer type icons and metadata, and make the selected file easier to identify.
- Link previews back to the originating knowledge base or conversation.
- Reserve the storage meter's space while loading and show a warning as storage approaches its quota.
- Offer a clear-filters action when the current filters produce no results.

## Knowledge Bases

- Add search and show each library's document count, processing and failed counts, and latest update time.
- Return document statistics with the library list using one grouped backend query over the libraries the caller can access.
- Keep the detail header and page frame stable with a full-page skeleton while the library loads.
- Add a summary of document totals, ready, processing, and failed documents, and total size.
- Give document rows type icons, status badges, processing indicators, preview buttons, and an actions menu. Document deletion now requires confirmation.
- Move sharing, member permissions, and library deletion into an overflow menu so the header fits narrow screens.

## Language and Settings

- Make relative dates follow the interface language and compare calendar days, including localized Today and Yesterday labels.
- Share byte-size formatting and file-type icons across the updated pages.
- Simplify the default speech-recognition description in English, French, Japanese, Simplified Chinese, and Traditional Chinese.

## Compatibility

- No database migrations or dependency changes are introduced relative to beta.3.
- Knowledge-base statistics are additive API fields. Deploy the updated backend and frontend together; the application image includes both.
- The release continues to include beta.3's home and sidebar loading improvements, independent code-block wrapping, and account wrapping defaults.

## Validation

- All 902 frontend tests passed across 153 test files on Node 22.
- TypeScript checking and the beta.4 production build passed; the built version identifier matches the package and About page.
- Go regression suites for `internal/store` and `internal/api` passed, including the new per-library document-statistics test.
- Focused ESLint checks passed for the shared administrator components, Files and knowledge-base pages, formatting helpers, and new frontend tests.

## Upgrade

After all four images for this tag finish publishing, administrators can select beta.4 in **System update**. For a manual Compose upgrade, set `deploy/.env` to:

```dotenv
IMAGE_TAG=2.5.1-beta.4
UPDATER_IMAGE_TAG=2.5.1-beta.4
```

Remove or align any explicit `APP_IMAGE_TAG` or `SANDBOX_IMAGE_TAG` overrides, then verify and deploy:

```bash
cd deploy
docker compose --env-file .env -f docker-compose.prod.yml config --images
docker compose --env-file .env -f docker-compose.prod.yml pull
docker compose --env-file .env -f docker-compose.prod.yml up -d --no-build
```

The tag triggers publication of `aivory-app`, `aivory-updater`, `aivory-sandbox`, and `aivory-sandbox-sidecar` under `ghcr.io/hjxwz123`, each tagged `2.5.1-beta.4` for `linux/amd64` and `linux/arm64`.
