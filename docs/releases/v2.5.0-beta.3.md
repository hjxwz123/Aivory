# Aivory v2.5.0-beta.3

> Test release / prerelease.

This release removes the Docmee AI PPT integration introduced in beta.2. The AI PPT sidebar entry, `/ppt` workbench, administrator settings, Docmee API endpoints, iframe SDK, and per-deck credit charging are no longer available.

The unified artifact panel, browser document editors (including PPTX text editing), structured folder uploads, and in-chat preview of generated files remain available. Saving an edited document as a new file still uses the existing upload API.

Existing credit ledger and usage records are retained as historical accounting data. This release does not delete stored presentations or change past charges. Previous beta.2 release notes remain in the archive to describe that published version.

## Upgrade

After the application and updater images finish publishing, administrators can select `v2.5.0-beta.3` from **System update**. For a manual Compose update, use:

```dotenv
APP_IMAGE_TAG=2.5.0-beta.3
UPDATER_IMAGE_TAG=2.5.0-beta.3
```

```bash
docker compose -f docker-compose.prod.yml pull app updater
docker compose -f docker-compose.prod.yml up -d --no-deps --force-recreate updater app
```
