# Aivory v2.5.1-beta.12

> Test release / prerelease fixing PostgreSQL channel updates and supporting OpenRouter Decisions endpoints.

## PostgreSQL Channel Updates

- Fix `ON CONFLICT DO UPDATE requires inference specification or constraint name (SQLSTATE 42601)` when saving a channel's supported models.
- Specify the existing unique index expression, `(channel_id, lower(trim(request_id)))`, in both channel-model upsert paths. PostgreSQL and SQLite use the same conflict target.
- Keep the existing case-insensitive request-ID matching and preserve the schema. No database migration is required.

## OpenRouter Decisions

- Accept complete `/decisions` and `/systemone` URLs in TypeSafe decision channels without appending a second resource suffix.
- Support `https://openrouter.ai/api/alpha/decisions` directly. OpenRouter's `/api` and `/api/v1` API roots also resolve to its TypeSafe-compatible `/api/v1/systemone` endpoint.
- Accept OpenRouter's `typesafe/` model namespace and the dated snapshots returned for a minor-version alias such as `typesafe/jev-1.13`. Concrete versions and explicit expected-model constraints retain strict version checks.
- Keep existing native TypeSafe API-root behavior, typed answer validation, token accounting, administrator pricing, request diagnostics, and request deadlines.
- Document configuration in [TypeSafe Decisions](https://github.com/hjxwz123/Aivory/blob/v2.5.1-beta.12/docs/typesafe-decisions.md).

Example configuration:

```text
Model protocol: TypeSafe Decisions (typesafe.decisions)
Channel Base URL: https://openrouter.ai/api/alpha/decisions
Channel API key: your OpenRouter API key
Model request ID: typesafe/jev-1.13
```

Model availability follows OpenRouter's current catalog and account access. This release does not make a credentialed inference request during preparation.

## Release Preparation

The backend compiled successfully. No test suites were run for these fixes or during release preparation, as requested. GitHub Actions builds the tagged source and verifies the packaged artifacts.
