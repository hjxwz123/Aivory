# Aivory v2.5.1-beta.13

Test release adding a dedicated OpenRouter Decisions protocol and continuous Volcano speech recognition, improving upload drafts and privacy settings, and fixing account isolation, conversation resource ownership, exports, and usage accounting.

## Models and OpenRouter Decisions

- Add **OpenRouter · Decisions** (`openrouter.decisions`) as a model-owned request protocol, with its own endpoint resolution and model discovery.
- Support `https://openrouter.ai/api/alpha` and the complete `/api/alpha/decisions` endpoint. Accept OpenRouter response IDs, provider names, and reported costs, and handle optional decision metadata without weakening TypeSafe's existing strict validation.
- Recognize model IDs containing `decision`, alongside supported Jev IDs, as decision models. Display translated model kinds in channel discovery results.
- Preserve explicitly selected discovery protocols. Generic gateways ending in `/api/v1` no longer become native DashScope embedding endpoints solely because of that suffix.
- Preserve existing saved model protocols. OpenAI-compatible Aliyun workspace URLs ending in `/compatible-mode` continue to request `/compatible-mode/v1/embeddings` when the model uses **OpenAI · Embeddings**.

## Conversation Drafts, Forks, and Exports

- Keep upload-only, unsent conversations out of history and search. Opening a page, typing text, or using the new-conversation shortcut does not create an empty conversation row.
- Limit each account to one unused upload draft across workspaces, projects, devices, and chat/draw scopes. Reuse the current draft; silently discard an eligible previous draft and its files when switching scope. No timed draft sweep is used.
- Restore pending draft attachments and stop uploads if a conversation reservation fails. Lock draft deletion against the first-message commit so a saved conversation is protected.
- Fork the selected message branch with independent file, document, generated-artifact, chunk, and vector IDs. Remap resource references so the fork can continue using attachments after the source conversation is deleted.
- Share immutable file bytes between source and fork while keeping ownership and indexes independent. Existing vectors are copied without another embedding request; quota checks still count independent file/document records.
- Include inline child conversations and archived conversations in full personal conversation exports.
- Group sidebar conversations by the user's local calendar date and refresh the groups at local midnight.

## Account Isolation and Access Revocation

- Clear conversation caches, private drawers, and workspace/project state on identity changes. Abort local stream readers and invalidate pending replies, reconnects, and delayed sends from the previous account.
- Remove persistent private-image caching from the service worker and clear legacy image caches. Private file and artifact responses use `Cache-Control: private, no-store`.
- Stop message-following connections after workspace access is revoked, including followers of another member's generation, without cancelling that member's request.
- Apply regular-chat concurrency and daily-message limits to private chat.

## Voice Recognition and Billing

- Support continuous Volcano live recognition in updated web and desktop clients. The default total recording deadline is disabled; upstream connections renew in bounded segments while capture continues.
- Default to a five-minute upstream segment and a 64 MiB segment byte threshold. Retain recent unsent audio in bounded queues and discard the oldest unsent audio when full. Preserve all recognized text in the composer.
- Reserve and settle voice credits per segment, using the PCM audio actually forwarded. Stop capture immediately when requested and drain pending audio before sending the end control.
- Bound browser WebSocket messages, upstream responses, decompression, and network waits. Retain the legacy single-connection event contract for older clients.
- Validate uploaded transcription duration from WAV samples or decoded audio instead of trusting client-reported duration. Withhold uploaded transcription results if billing settlement fails.
- Include `ffmpeg` in the application container for compressed audio decoding. Native API installations need `ffmpeg` in `PATH` for compressed formats.

Recommended live-recognition configuration (also the new defaults):

```dotenv
AIVORY_API_AUDIO_STREAM_MAX_SESSION=0
AIVORY_API_AUDIO_STREAM_MAX_BYTES=67108864
AIVORY_API_AUDIO_STREAM_SEGMENT_SESSION=5m
AIVORY_API_AUDIO_STREAM_BUFFER_SECONDS=30
```

Existing environment overrides take precedence. Old installed desktop clients retain the bounded single-connection behavior until upgraded. Network failures, upstream errors, insufficient balance, and permission revocation can still end recognition. See [continuous voice recognition](https://github.com/hjxwz123/Aivory/blob/v2.5.1-beta.13/docs/live-voice-streaming.md).

## Usage Accounting

- Include Gemini thinking tokens in output-token billing and daily token totals for streaming, final usage frames, and non-streaming responses.
- Enforce workspace monthly quotas and usage summaries from durable `usage_stats`, so deleting diagnostic usage logs does not restore already-used monthly allowance.

## Privacy Settings and Interface

- Move archived-conversation management and conversation/HTML sharing-link management into separate manager dialogs opened from the **Privacy** tab. Remove the standalone conversation-and-links settings tab.
- Show the theme-aware Aivory logo and wordmark during startup and full-screen loading.
- Refine login artwork, responsive form layout, and related application styles. Update translations in English, Simplified Chinese, Traditional Chinese, Japanese, and French.

## Upgrade Notes and Known Limitation

SQLite and PostgreSQL migrations add the draft scope and supporting indexes automatically. Existing saved model protocols and data are retained. A model previously saved with an incorrect native DashScope protocol on a generic gateway must be corrected manually to **OpenAI · Embeddings**.

Update the API and web frontend together, and install the new desktop client to enable its segmented audio transport. Shared original file bytes are retained until their final database reference is removed; deleting one user-managed attachment does not delete a fork's independent resources.

**Known limitation:** deleting an uploaded file from the administrator file inventory can still remove document indexes in other conversations or knowledge bases sharing the same storage path. The user-facing file deletion path is scoped to the selected conversation. The administrator deletion issue is not fixed in this release.

Backend compilation and vet, frontend typechecking, targeted linting, script syntax checks, and a production frontend build passed during implementation. No automated test suites or live provider calls were run. This release preparation does not repeat those checks; GitHub Actions builds the tagged source and verifies packaged artifacts.


Assets and images become available as their GitHub Actions builds finish. If a registry mirror has not synchronized the tag, use `ghcr.io` directly.
