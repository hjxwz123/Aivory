# Aivory v2.5.2

Stable release collecting all changes since **v2.5.1**, including every update from **v2.5.2-beta.1** through **v2.5.2-beta.12**. This release adds complete conversation exports, composable and safer Generative UI, maps, richer search and web reading, stronger administration and access controls, resilient backup and file storage, and a comprehensive system prompt editor.

## Conversation Sharing and Export

- Add PDF and TXT conversation exports alongside image and public-link sharing. JSON snapshots remain available from the sidebar's Export action. Exports include only selected completed user and assistant messages from the chosen branch; they omit reasoning, billing details, and internal model configuration.
- Generate one complete long PNG for image sharing, with standard and high-quality modes, bounded dimensions, localized progress, and resource fallbacks. Keep selections and drafts when changing formats or recovering from generation errors.
- Produce selectable-text, paginated A4 PDFs with tables, code, formulas, images, and page numbers. The authenticated export service uses isolated Chromium contexts with scripts and network/file access disabled, bounded concurrency, and input/output/time limits. Application containers include Chromium and CJK fonts; standalone API deployments can configure `AIVORY_PDF_CHROME_PATH`.
- Preserve nested components, SVG drawings, complex table spans, and column widths in exports. Fit wide tables to the page and replace interactive maps with static place names and links.
- Keep public conversation reads independent of session restoration. Missing shares show an unavailable state, while network, rate-limit, and server errors remain retryable; stale responses are ignored. Public shares retain scoped artifact links and frozen attachment metadata.

## Generative UI, Maps, and Chat

- Introduce composable preset components that can form complete layouts or appear inside Markdown paragraphs, headings, lists, quotes, and table cells. Components include layouts, cards, alerts, tabs, accordions, timelines, metrics, forms, charts, calculators, function plots, and maps.
- Share local state between controls and expressions within a UI group. Support validated form/button follow-ups while preserving streaming, read-only, and historical-message restrictions. Complex tables retain merged rows and columns; SVG drawings support common shapes and definitions while rejecting scripts, unsafe handlers, and foreign HTML.
- Improve recovery of incomplete or malformed component markup while retaining readable Markdown, literal code, escaped expressions, LaTeX, valid siblings, and empty table structures. Unsafe embedded content is dropped; unavailable state disables dependent actions. Legacy structured UI remains supported for existing conversations.
- Update the built-in Generative UI contract in five languages. Distinguish useful visual answers from requests for copyable HTML/CSS/JavaScript source, preserve administrator edits, and upgrade only untouched shipped defaults.
- Add configurable map components with numbered markers, address lookup, zoom/fit controls, place selection, and external links. Administrators can choose keyless OpenStreetMap/Photon or configure AMap credentials and security settings. Provider/credential-scoped caches, bounded lookups, and explicit failure states prevent silent provider switching or invented coordinates.
- Separate function plots automatically when their vertical ranges differ substantially, with shared-axis/separate-plot controls and synchronized coordinate inspection. Refine the composer Skills menu and preserve focus and drafts when inserting formulas during image uploads.
- Keep assistant reasoning collapsed initially with a compact live preview, allow long user messages to expand, keep branch navigation visible during streaming and in read-only transcripts, and retain direct copy/retry actions on mobile.
- Add configurable reply-wait animations with previews; the paper-plane animation remains the default.

## Search, Web Reading, and Research

- Add Tencent Cloud Yuanbao and DeepSeek web search, optional You.com search, and independent web-reading provider selection. Support documented provider options, citations, dates, excerpts, full-page text, and available image metadata.
- Configure Built-in reading with an optional Jina-compatible Reader fallback, DeepSeek Fetch, or AnySearch Extract independently of the search provider. Resolve a consistent configuration per invocation, validate public URLs, bound response sizes, and avoid exposing anonymous quota error bodies that may contain credentials.
- Apply credentials saved in the administrator console immediately, including explicitly cleared keys. Improve unconfigured search behavior in ordinary answers and Deep Research without inventing citations.
- Keep page content as untrusted reference material. Preserve provider-supplied content and image metadata through fetching, tools, streaming, saved history, public shares, and administrator inspection.

## Administration, Access, and Account Management

- Add administrator inventories for shared conversations, with owner inspection, link actions, filtering, and pagination. Add user-group filtering to the user list.
- Add message-editing controls at user-group, workspace, and member levels. Enforce their intersection on the server and recheck policy inside message-save transactions; preserve existing access, authorship, archive, guest, and read-only restrictions. Existing groups, workspaces, and members default to allowed.
- Add per-user-group model access controls and enforce them across chat admission, existing-turn operations, private chat, task execution, and model-backed tools. Preserve current access by default, include policies in backup/restore, and refresh connected model catalogs after changes.
- Combine website access, popup messages, and notifications into **Admin > System > Website & notifications**. Administrators can close the website with an optional plain-text maintenance message while authenticated active system administrators retain console access. Keep authentication, password recovery, health checks, and payment settlement available.
- Localize registration and recovery email in Simplified Chinese, Traditional Chinese, English, Japanese, and French. Replace recovery codes with expiring, single-use password-reset links; add welcome, membership activation, and renewal messages, plus multiple SMTP accounts and per-message previews/settings.
- Allow optional workspaces in registration domain rules. Rules without a workspace preserve personal space; personal-space locking requires a workspace. Preserve member bindings and lock overrides when editing, allow target changes only before enrollment, and migrate existing databases automatically.
- Improve mobile administrator layouts for dialogs, selects, popovers, forms, tabs, tables, editors, and detail views while preserving keyboard and screen-reader labels. Standardize loading, empty, and error states; keep existing records visible during refresh and provide retry actions.
- Add **Admin > AI & Models > System Prompts**, a validated editor for 275 registered prompts and five-language conversation fragments. Manage ordinary- and decision-model prompts for routing, documents, memory, moderation, titles, compaction, verification, knowledge bases, deep research, image workflows, tool guidance, and document generation. Blank overrides restore built-in defaults; invalid or incomplete updates are rejected atomically.
- Include prompt overrides in backups and audit classification. Apply saved overrides to subsequent requests, invalidate vision evidence when related prompts change, and keep format-sensitive requirements and placeholders visible. Existing installations continue using defaults until an administrator saves overrides.
- Improve channel model discovery diagnostics, trim credential whitespace, preserve model bindings after configuration load errors, and remove deleted model capabilities on subsequent saves.

## Model Usage and Search Configuration

- Preserve cache read/write token counts from OpenAI Chat Completions and Responses, common compatible gateways, and Gemini streaming and prompt-tool responses. Accumulate usage over tool rounds without double-counting cumulative frames, and retain earlier cache details if later frames omit them.
- Request streaming usage in OpenAI prompt-tool mode and expose normalized cache usage in administrator call logs and usage details. Price cached input separately when provider totals already include cached tokens; retain Anthropic's separate input/cache accounting.
- Keep credentialed and keyless You.com request modes, citation parsing, and bounded rate-limit retries. Do not treat zero cache usage as evidence that caching should have occurred, and do not infer cache writes from Gemini generation usage or DeepSeek cache misses.

## Website Notifications and Desktop Client

- Add opt-in reply-completion notifications, stored per account and device. Open the originating conversation and workspace while checking the active account; scope browser notifications to their originating tab and support native notifications in updated desktop builds.
- Bundle the notification runtime and updated frontend with desktop installers. Preserve configured server addresses across updates and support administrator-published stable or beta versions when a matching OS/architecture package is available.
- Build Windows x64, Linux x64, macOS arm64, and macOS x64 installers with SHA-256 checksums. Official packages use first-launch server configuration rather than a hard-coded deployment URL. macOS packages are ad-hoc signed when Developer ID credentials are unavailable and are not notarized without Apple credentials.

## Backup, File Storage, and Reliability

- Reconcile uncertain database commit acknowledgements before deciding whether uploaded, generated, or mirrored file bytes can be removed. Coordinate writes and cleanup across API processes, recheck references under the storage lock, and use exclusive file creation to prevent overwrites.
- Repair confirmed missing-file references before full exports while preserving conversation text, branches, tool pairs, and healthy files. Abort on unavailable storage, access errors, or unsafe paths. Pin a filesystem snapshot before compression so concurrent deletion cannot invalidate archive references.
- Harden full restore with writer coordination, persistent recovery journals, rollback state, and database commit witnesses. Keep required Qdrant compensation archives and block further storage changes when a failed restore needs operator reconciliation. Mark archived in-progress replies interrupted and prevent old workers from finalizing them.
- Upload backups in acknowledged chunks, reduce chunk size after proxy `413` responses down to 256 KiB, and restore from a ZIP already in the configured server backup directory without sending its bytes through the browser or reverse proxy. Run restore as a background job with separate upload, validation, and restore status, while retaining transactional validation and rollback.
- Stop polling when its owning page/session no longer needs it, end follower event streams promptly after access revocation, and allow scoped restore-status checks to continue if login expires during restoration.
- Generate UUIDs on HTTP origins that lack `crypto.randomUUID()`. Keep mobile account, language, workspace, and conversation-move menus within the visible viewport, with submenu back navigation and safe-area spacing.

## Upgrade Notes

- Deploy the API and frontend together. Database migrations add message-editing permissions, model-group access, and optional-workspace domain rules automatically on supported SQLite and PostgreSQL installations. Existing policies remain allowed unless explicitly restricted.
- Pull the application container image to obtain Chromium and CJK fonts for PDF export. Standalone API deployments need a compatible Chromium installation and `AIVORY_PDF_CHROME_PATH`. No browser-side Chrome installation is required.
- OpenStreetMap/Photon remains the default map provider. Configure AMap keys and security code before selecting AMap. The retired `AIVORY_LLM_TOOL_TIMEOUTS_3` setting is replaced by `image_timeout_sec` on the image model; zero omits the model-specific timeout while parent cancellation and generation deadlines still apply.
- Configure search and web reading independently under **Admin > Tools**. Existing deployments can continue using the built-in reader and optional Jina-compatible fallback.
- A full backup exported by beta.7 or later uses archive format v3 and can be restored if it contains every file referenced by its database records. Missing file bytes cannot be recovered by export repair. Keep the source ZIP until restore succeeds; use the server-directory restore path for archives that exceed proxy request limits.
- Interrupted restores may leave `.aivory-storage-*.lock.recovery` journals beside storage roots. Reconcile these using the deployment recovery procedure before removing them or resuming storage writes.
- Existing desktop clients may need one manual installation if their update checker predates beta.3 and cannot detect administrator-published prereleases. GitHub releases do not automatically publish desktop updates to each deployment; administrators must select the version and matching installers in **Admin > System > Desktop Client** and enable publication.
- Prompt overrides take effect on subsequent requests. Existing installations retain built-in defaults until overrides are saved; already generated titles, summaries, and memories are not rewritten. Keep required fields, enums, protocols, and placeholders when editing format-sensitive prompts.

## Validation

Across beta.1 through beta.12, focused frontend/API/store/LLM/tool tests, TypeScript checks, scoped lint, production builds, Go tests and vet, and real-browser checks covered exports and PDF isolation, Generative UI composition and recovery, maps, search settings, permissions, website closure, email recovery, storage and restore failures, mobile administration, prompt editing, and knowledge-base retries. Provider integrations used simulated responses where live vendor credentials were unavailable. PostgreSQL migration behavior was not exercised against a local PostgreSQL database; the migration is included for automatic deployment startup. Release preparation should verify version/lockfile consistency and workflow configuration; tagged CI builds the desktop packages and checks packaged contents and macOS signatures.
