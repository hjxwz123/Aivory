# Aivory v2.5.2

Stable release collecting every functional change published in **v2.5.2-beta.1** through **v2.5.2-beta.12**. The detailed entries below retain each test release's feature, fix, compatibility, and upgrade notes. Beta.10 includes the previously drafted beta.9 changes; repeated items are retained under their published beta notes so the full release history is explicit.

## Detailed Beta Changelog

### Beta 1

First test release of the 2.5.2 series, covering all changes since **v2.5.1**. This release adds PDF, JSON, and TXT conversation exports, improves long-image sharing, preserves page state when returning to the app, fixes public-share loading races, and refines Generative UI and administrator layouts.

#### Conversation Sharing and Exports

- Add **PDF**, **JSON**, and **TXT** alongside link and image sharing in desktop and mobile conversation menus. Reuse message selection, full-history selection, preview, saving, and native file sharing where the device supports it.
- Export only the selected branch's completed user and assistant messages. JSON uses an explicit versioned snapshot; TXT produces readable text. Exclude reasoning, billing details, and internal model configuration.
- Keep image exports as **one complete long PNG**. Remove image pagination and page-specific save controls. Reject selections beyond the single-image limits instead of silently cropping or splitting them.
- Speed up image capture using a simplified static document rather than cloning the full interactive chat. Offer standard quality (up to 1.5x) and high quality (up to 2x), within a 16,384-pixel edge and 16-megapixel canvas limit.
- Prepare images with bounded concurrency and timeouts, reuse required font CSS, and cache up to two generated files with account, workspace, conversation, content, language, theme, format, and quality isolation. Retain message selections when generation fails or the format changes, and preserve the composer draft when leaving selection mode.
- Preserve math, code, long lists, and dark-theme SVG chart colors. Show localized generation stages, resource fallbacks, timeouts, and PDF-service errors.
- Generate selectable-text, paginated A4 PDFs with tables, code, formulas, images, and page numbers. Add an authenticated export endpoint with conversation authorization, sharing/export permission checks, signed requests, and no-store responses.
- Render PDFs in a lazily started server-side Chromium instance with isolated request contexts, disabled scripts and network/file access, bounded concurrency, and input/output/time limits. The application container now includes Chromium and CJK fonts; binary deployments can set `AIVORY_PDF_CHROME_PATH`.

#### Foreground Recovery and Page State

- Stop applying pending frontend deployments merely because a tab becomes hidden or returns to the foreground. Check for updates in the background and apply a pending deployment on a subsequent visible route navigation, retaining streaming protections and reload-loop backoff.
- Avoid redundant language-change events during account profile synchronization. Preserve unsaved account-name edits for the same account while still resetting them when switching accounts.
- Decouple data loading from translation changes in administrator conversation lists/details, user libraries, model editing, model quotas, and user files. Preserve branches, expanded reasoning, filters, pagination, and editing drafts across profile refreshes.
- Restore read-only branch navigation in administrator conversation inspection while keeping message mutation and generation actions unavailable.

#### Public Conversation Links

- Make public snapshot reads independent of session restoration. Public reads omit account credentials, cookies, device headers, and request signatures, so a session restored during loading no longer discards a valid shared conversation as an account-change error.
- Keep authenticated cloning and private request isolation unchanged.
- Show the unavailable-link state only for a missing share. Network failures, rate limits, and server errors now show a retryable loading error. Ignore stale responses after navigating to another share or retrying.
- Add translated recovery messages in English, Simplified Chinese, Traditional Chinese, Japanese, and French.

#### Generative UI and Function Graphs

- Refine the preloaded presentation instructions to distinguish information presentation from copyable source code. Encourage useful presets for comparisons, calculations, trends, plans, and exploration without requiring an explicit visualization request.
- Reserve `aivory-html` for custom interactive visuals, simulations, diagrams, and tool-like interfaces that presets cannot express. Requests for HTML/CSS/JavaScript source, snippets, templates, debugging, or code explanations use ordinary Markdown/code fences. Keep code in normal fences when combining it with a separate visual explanation.
- Apply the output contract to automatically loaded and explicitly selected Generative UI skills, and update all five localized presentation prompts. Upgrade untouched built-in defaults by fingerprint while preserving administrator customizations.
- Automatically separate function graphs when their vertical ranges differ by more than 100x. Each plot retains its real coordinates, keeping a small-amplitude curve such as `sin(x)` visible beside a large polynomial. Add **Shared axes / Separate plots** controls and retain synchronized coordinate inspection.
- Simplify the composer Skills menu to a single line per skill: icon, name, and selection state.

#### Settings and Administrator Interface

- Remove redundant refresh buttons from archived-conversation and shared-link managers; retain automatic loading and updates after actions. Add icons to their Privacy settings management buttons.
- Keep selection, ordering, and action columns compact in the shared administrator table. Allocate remaining width to data columns, fixing the large blank selection area in the file list.
- Ignore local core-dump files in Git.

#### Upgrade and Compatibility

- Update the API and frontend together for PDF export. Docker users must pull the new application image to obtain Chromium and CJK fonts; users of a standalone API binary must provide an available Chromium installation. No Chrome installation is required on client devices.
- Image, JSON, and TXT files are generated locally. PDF preparation embeds resources locally and submits the resulting document to the authenticated API for printing.
- Existing edited Generative UI skills remain customized. The shared output contract still supplies the code-versus-UI boundary; untouched shipped skill text updates automatically on server startup.
- Desktop installers bundle the updated frontend locally, use first-launch server configuration, and retain saved server settings when updated. These official packages do not hard-code a deployment URL.
- This is a prerelease. The latest stable release remains **v2.5.1**.

- Share local state between controls and expressions in the same UI group. Buttons and forms can submit follow-up messages with validation, retry feedback, and duplicate-submission guards. Preserve streaming, read-only, and historical-message restrictions.
- Render nested SVG drawings with paths, shapes, text, gradients, clipping, markers, filters, and isolated local definitions. Keep SVG references scoped to each drawing and reject scripts, arbitrary handlers, and foreign HTML.
- Support complex tables with merged rows and columns, multiple header and body groups, footers, unequal column widths, and nested components. Flat tables retain optional sorting and filtering; merged tables preserve their original structure.
- Update the built-in skill and all five localized presentation contracts to teach canonical component tags. Retain legacy structured UI parsing for existing conversations without advertising the old output format in prompts. Upgrade untouched built-in skill defaults while preserving administrator edits.

#### Maps and Administrator Settings

- Add the canonical `map` component with `map-point` children. Accept verified coordinates or specific addresses, fit the viewport to located places, and provide numbered markers, zoom and fit controls, place selection, and external place links.
- Allow cards, tables, tabs, forms, images, buttons, and SVG inside selected-place details. Address lookup failures remain visible without inventing coordinates.
- Add **Admin > Tools > Maps** to choose between the default keyless OpenStreetMap/Photon service and **AMap**. The selected provider handles both address lookup and map rendering.
- For AMap, configure the Web Service key, JavaScript API key, and security code in the administrator panel. Keep the Web Service key and security code server-side and use the built-in SDK proxy. Support geocoding with POI fallback and coordinate conversion at provider boundaries.

#### Sharing and Exports

- Remove JSON from the conversation's Share submenu and file-format selector. JSON conversation export remains available from the sidebar's Export action.
- Replace native sharing format and image-quality dropdowns with themed custom controls. Escape closes an open dropdown before leaving message selection.
- Preserve nested components, SVG definitions, complex table spans, and column proportions in image and PDF exports. Fit wide tables to the export page and show static place names and links instead of an unmounted map loader.
- Retain PNG, PDF, and TXT previews and downloads, message selections after failed generation, cached exports, and account isolation.

#### Composer and Image Reliability

- Fix formula insertion while an image is uploading. Keep keyboard focus in the formula editor, preserve the draft when upload finishes, and restore composer focus after closing the editor on desktop and mobile.
- Preserve existing image attachments when editing and resending a user message into a sibling branch. Validate the original message and attachment ownership on the server.
- Apply the administrator's image-model timeout consistently to direct drawing and chat image tools, including normal, fast, automation, and research paths. Pause the tool-time budget during image generation and remove the old fixed tool timeout and response-header timeout from image requests. Parent cancellation and generation deadlines still apply.

#### Upgrade and Compatibility

- Update the API and frontend together to use the new map endpoints and administrator settings. No new database migration is required.
- OpenStreetMap/Photon remains the default and requires no API key. AMap is optional and must be configured by an administrator before selecting it.
- `AIVORY_LLM_TOOL_TIMEOUTS_3` is retired. Configure `image_timeout_sec` on the image model in the administrator panel; `0` adds no model-specific timeout while retaining parent cancellation and deadlines.
- Desktop installers bundle the updated frontend locally, ask for a server address on first launch, and retain saved server settings on upgrade.
- This is a prerelease. The latest stable release remains **v2.5.1**.

### Beta 7

Test release covering all changes since **v2.5.2-beta.6**. Protects stored files against uncertain database commits and concurrent cleanup, repairs missing-file references before full exports, hardens interrupted backup restores, and fixes HTTP-origin UUID generation and mobile navigation menus.

#### Stored Files and Backup Exports

- Reconcile failed database commit acknowledgements when saving uploads, documents, PPT mirrors, and tool artifacts. Treat a verified commit as successful and retain file bytes when the outcome remains uncertain.
- Coordinate file writes and physical cleanup across API processes sharing the same storage. Cleanup rechecks database references while holding the storage lock, and new files use exclusive creation to prevent accidental overwrites.
- Before exports that include files, remove records for confirmed missing local artifacts, uploads, and documents, and clean their references in messages, shared transcripts, compaction media, PPT decks, and skill assets. Document removal also queues vector cleanup through the normal lifecycle.
- Preserve message text, tool-call pairs, conversation branches, and healthy files in mixed artifact groups. Missing uploaded attachments keep a filename and deleted marker; artifact-only messages retain a readable unavailable-file notice.
- Abort repair on unavailable storage roots, access errors, or unsafe paths. Database-only exports do not perform missing-file repair.
- Pin a filesystem snapshot before archive compression so normal deletion cannot invalidate exported database references. Release the storage lock after pinning, allowing writes to resume during compression and Qdrant export.
- Recheck structured file references when an assistant reply finishes so an older generation cannot reintroduce references removed by repair. Validate skill asset source files before saving skill configuration.

#### Backup Restore Recovery

- Coordinate full restores with file writers before replacing live directories. Reconcile database commit errors using a witness written in the restore transaction.
- Write persistent recovery journals before publishing restored directories. If a restore crashes, rollback fails, or its commit outcome cannot be verified, retain recovery state and block subsequent storage changes until an operator reconciles it.
- Preserve previous file trees and required Qdrant compensation archives. Store Qdrant recovery ZIPs beside the persisted upload root rather than in temporary process storage.
- Mark archived assistant replies in `streaming` or `stopping` state as interrupted, preserve their partial content, and clear old generation and compaction leases. Prevent old workers from finalizing those restored replies.

#### HTTP Compatibility and Interface

- Generate UUIDs on HTTP origins where `crypto.randomUUID()` is unavailable, using cryptographically secure random bytes. Apply the helper to requests, chat layout, email configuration, and reply notifications.
- Keep mobile account menus, language and workspace submenus, and conversation move menus inside the visible viewport. Support submenu back navigation, long scrollable lists, and sidebar safe-area spacing.
- Align administrator audit and tool log empty states with usage logs.

#### Upgrade Notes

- Deploy the updated API and frontend together. These changes require no database schema migration.
- Exports that include files now repair confirmed missing-file metadata in the live database before creating the archive. This removes broken references; it cannot recover bytes that are already missing. Conversation text and branches remain available.
- An interrupted restore may leave `.aivory-storage-*.lock.recovery` journals beside the storage roots. Follow the recovery procedure in [`deploy/README.md`](https://github.com/hjxwz123/Aivory/blob/v2.5.2-beta.7/deploy/README.md) or [`deploy/README.zh-CN.md`](https://github.com/hjxwz123/Aivory/blob/v2.5.2-beta.7/deploy/README.zh-CN.md) before removing them or resuming storage writes.

### Beta 8

Test release covering changes since **v2.5.2-beta.7**. Makes large backup restores resilient to proxy limits and long-running network requests, and adds direct restore from a ZIP already copied to the server.

#### Backup Upload and Restore

- Upload full backups in acknowledged chunks and restore them as a background job. The page shows actual upload progress and separately reports validation and restore status.
- Reduce chunk size automatically after a proxy responds with `413 Content Too Large`, down to 256 KiB. This works around smaller per-request proxy limits; `MAX_BACKUP_BYTES` remains the overall archive limit.
- Restore a regular `.zip` or `.ZIP` directly from the configured server backup directory. The archive bytes do not pass through the browser, Cloudflare or the reverse proxy, and the source ZIP is retained.
- Keep the existing archive validation, transactional restore, recovery journals and rollback behavior for both restore sources.
- Update backup status polling and bypass Service Worker interception for long requests, avoiding browser-enforced Service Worker fetch deadlines during uploads and restores.

#### Reliability

- Stop background polling requests when their owning page or session no longer needs them.
- End follower event streams promptly when access is revoked.
- Keep restore status checks available through the scoped job capability if the user's login session expires during restoration.

#### Upgrade Notes

- Deploy the updated API and frontend together. No database schema migration is required.
- Full backups exported by **v2.5.2-beta.7** use archive format v3, which this release still supports. A complete, valid beta.7 ZIP can be restored directly after upgrading. The archive must contain every file referenced by its database records; an older incomplete archive cannot restore missing file bytes.
- For large archives or proxy `413` errors, copy the ZIP into the displayed `BACKUP_DIR` on the server, refresh **Admin > Backup & Migration**, select it under **Restore from server directory**, and type `REPLACE`. Keep the original ZIP until the restore is confirmed successful.
- For browser uploads, Nginx must allow each chunk request plus multipart overhead. For example, `client_max_body_size 8m;` allows the current 4 MiB maximum chunk. Timeout settings control inactivity between upstream I/O and do not change body-size limits.
