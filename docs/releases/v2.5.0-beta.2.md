# Aivory v2.5.0-beta.2

> Test release / prerelease.

`v2.5.0-beta.2` adds the Docmee / 文多多 AI PPT workbench, credit-safe presentation billing, and in-chat preview controls for generated files.

## AI PPT workbench

- Add an **AI PPT** page and sidebar entry that embeds the Docmee presentation creator through its iframe SDK.
- Configure the integration from **Admin → Credits and quotas → AI PPT (文多多)**: enable switch, API key, per-deck price, creator version, token lifetime, API origin, SDK URL and optional international or proxy URLs.
- Keep the sidebar clean on deployments that do not use Docmee: **AI PPT** appears only after a usable API key is configured and the integration is enabled. Direct `/ppt` links show an unavailable state until then.
- Keep the Docmee API key on the server. The browser receives only a short-lived user-scoped iframe token, and upstream errors do not expose provider details.
- Support the China default, the international Docmee origin, an administrator-managed proxy, or a self-hosted SDK script.
- Document the setup, availability rules, billing protocol and deployment options in [the AI PPT integration guide](../ai-ppt-docmee.md) ([简体中文](../ai-ppt-docmee.zh-CN.md)).

## Credits and usage

- Reserve the configured credits before generation begins, settle one charge when Docmee reports the generated presentation, and release unused holds when appropriate.
- Use the Docmee presentation ID as an idempotency key. SDK retries, page reloads and duplicate events cannot debit the same deck twice.
- Block generation with a clear top-up state when the user cannot cover the configured price. When platform credits or the per-deck price are disabled, generation remains free.
- Record settled AI PPT charges in usage logs and usage statistics under the new `ppt` purpose, so administrator billing and usage pages show the actual debit.

## Generated file preview

- Add a preview control alongside the download control on generated-file cards in chat.
- Open the existing Artifact Panel for HTML, PDF, Word, PowerPoint, spreadsheets, text and supported image artifacts.
- Preserve safe URL handling and image lightbox behavior. MIME type fallback improves preview selection when a generated filename has no useful extension.

## Release fixes

- Resolve the document-copy upload client method that blocked the first beta. The preview editor now uses the existing `POST /api/files` upload pipeline to save edited files as new attachments.
- Resolve the merge collision between beta.1's compatibility fix and PR #32's more complete document-copy client method.

## Upgrade

This is a prerelease intended for testing. Back up the database, uploaded files and generated artifacts before enabling it on a production deployment.

After the application and updater images finish publishing, administrators can select `v2.5.0-beta.2` from **System update**. For a manual Compose update, preserve the deployment's existing settings and use:

```dotenv
APP_IMAGE_TAG=2.5.0-beta.2
UPDATER_IMAGE_TAG=2.5.0-beta.2
```

```bash
docker compose -f docker-compose.prod.yml pull app updater
docker compose -f docker-compose.prod.yml up -d --no-deps --force-recreate updater app
```

Database migrations run automatically on startup. The AI PPT integration stays unavailable until an administrator configures and enables it.
