# Aivory v2.5.1-beta.11

> Test release / prerelease with richer visual answers, adaptive web and image search, and a macOS fullscreen close fix.

## Desktop

- Fix the black screen that could appear when closing a fullscreen macOS window. The app waits for HTML and native fullscreen to finish before minimizing.
- Cancel pending minimize/hide actions when restoring the app from the Dock or menu, so a delayed action cannot hide a restored window.
- Include the new window lifecycle module in packaged installers and the release packaging checks.
- Update the web About page to show the current release version.

## Generative UI

- Simplify the built-in `generative-ui` instructions and encourage useful inline UI alongside prose when it improves reading, comparison, or understanding. Renderer limits remain enforced in code.
- Add rich table cells for images, links, lists, and descriptive text, with configurable column alignment and width, captions, sticky headers, and contained scrolling.
- Scale external HTTP(S) images to fit table cells without cropping or stretching. Image loading and failure states keep the same dimensions.
- Keep existing primitive-cell tables compatible. Update untouched built-in Skill defaults while preserving administrator customizations and model bindings.

## Web and Image Search

- Let the model adapt SearXNG categories, freshness, language, starting page, engine selection, and safe-search options to the user's request. Per-call engine selection stays within the administrator's configured list.
- Add a SearXNG **Results per keyword** setting in Admin → Tools → Web search. Choose 1–50 results per keyword; for example, 20 targets up to 20 distinct results for each query in a batch.
- Make the saved administrator result count authoritative, including for older tool calls that still send `top_k`. Fetch subsequent pages only when needed, preserve filters, and retain available results if a later page fails or the search deadline is reached.
- Preserve complete SearXNG snippets instead of truncating them to 320 characters. Search snippets remain separate from full-page reads.
- Support image-category searches and a responsive gallery with source links, full-image previews, thumbnail fallback, and unavailable-image states.
- Preserve image and thumbnail metadata from ordinary search results without automatically displaying a gallery. Display can be requested when images help the answer.
- Retain image metadata from existing HTML page reads and Jina-compatible Markdown output. `web_fetch` can display those images when requested, without additional server-side image downloads.
- Keep image metadata through streaming, saved conversation history, shared transcripts, and administrator conversation views. Add translations in all five supported languages.

Existing databases require no new schema migration. Installations without a saved SearXNG result count keep their previous result-count behavior until the updated search configuration is saved.

## Release Preparation

Changes were committed and pushed in separate feature batches. No additional test suites were run during release preparation, as requested. GitHub Actions builds the tagged source and verifies the packaged release artifacts.
