# Aivory v2.5.2-beta.12

Test release covering changes since **v2.5.2-beta.11**. Adds a comprehensive administrator system prompt editor, refines tool routing, preserves omitted model parameters, improves chat message controls, and fixes embedding retry and timeout handling.

## Administrator System Prompt Editor

- Add **Admin > AI & Models > System Prompts** at `/admin/settings/system-prompts`, with 275 registered prompts and five-language conversation fragments.
- Edit ordinary-model and decision-model prompts independently for tool routing, document selection, memory extraction and review, and moderation. Also cover title generation, context compaction, answer verification, knowledge-base processing, deep research, image workflows, tool descriptions and protocols, and built-in document generation guidance.
- Show each prompt's built-in default, required response format, and required placeholders. Leaving an override blank restores the built-in default.
- Validate all changed prompts before saving. Reject unknown prompts, invalid values, oversized content, and missing required placeholders without partially applying an update.
- Include prompt overrides in configuration backups and audit classification. Saved changes apply to subsequent requests; changing vision prompts also invalidates the corresponding image-evidence cache.
- Keep the existing context-compaction extra instruction synchronized with the new editor. Model selection and routing choice keys remain controlled by the existing model policies.

## Tool Routing and Model Parameters

- Describe available tool purposes and include uploaded-image, uploaded-file, attachment-type, and conversation-file context in routing requests.
- Clarify the distinction between a response that can be completed with text or search and an outcome that requires another tool, including file generation and Python-assisted data analysis.
- Continue selecting the decision-model tool scope from `choice` only.
- Leave `param_controls` dropdowns unselected when the administrator has not configured a default. Omit unset parameters from requests instead of automatically choosing the first option.
- Preserve the current turn's parameter omission when regenerating a response, so an older turn's parameters are not restored.

## Chat Experience

- Keep reasoning collapsed initially and show a compact live preview drawn from actual model reasoning or the current tool. Allow users to expand the complete trace.
- Collapse long user messages with explicit expand and collapse controls.
- Place branch navigation beside message actions while keeping it visible during streaming and in read-only transcripts.
- Keep copy and retry directly accessible on mobile, with additional actions and usage details in the action sheet.

## Knowledge-Base Reliability

- Restore retries for retryable embedding network and response-header timeouts while retaining the bounded provider-attempt timeout.
- Start the provider-attempt timeout after acquiring a local concurrency slot, so waiting in the local queue does not consume the provider's request budget.
- Report the actual number of attempts and distinguish provider-attempt timeouts from underlying network timeouts.

## Upgrade Notes

- Deploy the frontend and API together to use the new administrator page and prompt catalog.
- Existing installations continue using the built-in defaults until administrators save overrides. Already-generated titles, summaries, and memories are not rewritten.
- Format-sensitive prompts must retain their documented fields, enums, protocols, and required placeholders. The editor displays these requirements for each prompt.
- After desktop installers finish publishing, administrators can select **v2.5.2-beta.12** and its matching installers in **Admin > System > Desktop Client** to publish the update to their users.
- This release is marked as a GitHub prerelease.

## Validation

- TypeScript checking and targeted ESLint checks.
- 25 frontend tests covering the system prompt editor and administrator navigation.
- Go tests covering the prompt catalog, administrator settings, backup validation, audit classification, ordinary and decision model paths, routing, moderation, title generation, compaction, vision evidence, research, and provider finalization.
- Full Go knowledge-base and tool package test suites.
- Browser checks of the new editor on desktop and mobile, including dark mode, save behavior, overflow, and page errors.
- Production frontend build and whitespace checks.
